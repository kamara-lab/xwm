# xwm.datasets

Readers for recorded corpora: the LeRobot layout on the Hugging Face Hub (DROID, the Open X-Embodiment mirrors, LIBERO), Open X-Embodiment in native RLDS, LIBERO and RoboMimic HDF5, and OGBench and Minari for offline RL. All four produce the same field layout `xwm.data` does, so a recorded dataset and a generated one are interchangeable to every model in the library.
